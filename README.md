

# 🚀 Python Programs Repository

**Learn • Practice • Build • Explore**

A structured, beginner-friendly collection of Python scripts, web applications, networking tools, and data analysis projects.


## 🌟 About the Repository

This repository is designed as a practical learning workspace. It contains clean, well-documented Python programs that gradually increase in complexity. Whether you are learning basic loops, building web apps, or exploring cybersecurity, there are examples here to help you practice.

---

## 🛠️ Technology Stack

This repository utilizes the following core technologies:

* **Python:** The core language used for logic, automation, and security scripts.
* **Flask:** A lightweight web framework used to build interactive, browser-based applications.
* **NumPy:** A high-performance mathematical library for processing arrays and complex calculations.
* **Pandas:** A data analysis toolkit used for reading, cleaning, and filtering datasets (like CSVs).
* **Matplotlib:** A visual graphing library used to turn raw data into line charts, bar graphs, and pie charts.

---

## 📂 Project Categories

Here is a breakdown of the programs included in this repository:

### 🔢 1. Core Logic & Math

* **Calculator:** Basic arithmetic operations.
* **Armstrong Number & Palindrome:** Logic validation.
* **Fibonacci & Factorials:** Loops and recursion practice.
* **String Manipulation:** Reverse strings, word counters, and string slicing.

### 📁 2. File Handling

* **Read & Write:** Opening, modifying, and saving text files dynamically.
* **Data Parsing:** Counting specific words or lines within a document.

### 🌐 3. Flask Web Applications

* **Bus Ticket Booking:** Includes passenger and bus management routes.
* **Resume Builder:** Generates formatted resumes based on user input.
* **Attendance Tracker:** Web interface to log and track student/employee presence.
* **Marksheet Generator:** Calculates grades and displays student reports.

### 🔐 4. Networking & Cybersecurity

* **Client-Server Chat:** Basic socket programming for two-way communication.
* **Port Scanner:** Identifies open ports on a target IP address.
* **Password Generator:** Creates highly secure, randomized passwords.
* **IP & IPv6 Checker:** Validates and analyzes network addresses.

### 📊 5. Data Analysis

* **CSV Handler:** Scripts to import, filter, and export spreadsheet data using Pandas.
* **Data Visualizer:** Generates graphs and charts from raw data using Matplotlib.

## ⚙️ Installation & Setup

Follow these steps to set up the code on your local machine.

### 1. Install Python

Download Python from [python.org](https://www.python.org/downloads/). During installation, **make sure to check the box** that says `Add Python to PATH`.

### 2. Download the Code

Download this repository as a `.zip` file using the green **Code** button at the top of the page, and extract it to your computer. Open your terminal or command prompt and navigate to the extracted folder.

### 3. Update pip and Install Libraries

It is highly recommended to update `pip` (Python's package manager) before installing the required libraries:

```bash
python -m pip install --upgrade pip

pip install flask numpy pandas matplotlib

```
